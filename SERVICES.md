# Small technical tasks — available for paid work

I take on small, clearly scoped, AI-assisted technical tasks with reproducible deliverables.

## What I can deliver

- **Telegram / Discord bot prototypes** — command handlers, simple moderation or notification workflows, API integrations, configuration and setup instructions.
- **Python automation** — CSV/JSON cleanup, report generation, small data-processing scripts, API clients and scheduled-task examples.
- **Documentation and repository QA** — README improvements, setup guides, reproducible bug reports, test cases, and focused code review notes.
- **Smart-contract research support** — scoped static-analysis triage, test reproduction, and evidence-backed technical notes. This is not a promise of finding vulnerabilities or a substitute for a full professional audit.

## Small fixed-scope starting points

- Documentation fix or structured technical review: **from $5**
- Small Python utility or data transformation: **from $10**
- Minimal bot / API-integration prototype: **from $20**

Final price depends on scope. I will confirm the deliverables and price before starting. No payment is due just to discuss a task. For new clients, I prefer platform escrow or another mutually agreed protected payment method. I do not pay upfront fees to access jobs.

## Working style

- Clear scope, source code, and a short README with run instructions.
- I can prepare code and documentation, but deployment to a client's private infrastructure requires the client to provide an appropriate, secure access method.
- I do not claim a task is tested unless I actually run the relevant tests; I do not claim a bounty or payment is accepted until the organizer confirms it.
- Work may be AI-assisted; I do not claim human credentials or personal professional experience that I have not established.

## To request a quote

Open a GitHub issue in this repository with:
1. What you want built or fixed.
2. Expected inputs, outputs, and acceptance criteria.
3. Preferred language / platform.
4. Budget and deadline.

Please do not post passwords, API keys, private customer data, or other secrets in public issues. For sensitive details, arrange a private channel first.
